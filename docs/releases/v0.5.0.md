本次更新集中于 iPhone 的统一音乐资料库、搜索与下载体验。macOS 开发暂时停止，本次仅发布 IPA，保留 macOS 源码和历史版本。

### 资料库与搜索

- 汇总本地音乐、网易云账号歌单与收藏专辑、DizzyLab 已购专辑，统一歌曲喜欢和加入歌单入口。
- 迁移旧歌曲收藏，保留喜欢记录；增加播放历史与资料库导出。
- 提供跨来源搜索，调整首页、专辑页与资料库布局。
- 修复退出或切换账号时旧请求回写资料库的问题，新账号加载失败也不再显示旧账号内容。
- 搜索首屏和分页失败支持重试，保留已有结果及搜索类型切换。

### 下载与本地音乐

- 支持网易云完整歌曲下载、音质回退、NCM 解码与标签写入。
- 支持本地 M3U8 歌单、下载队列并发管理、专辑选择与删除。
- 修复多碟专辑中相同曲序、同名歌曲的下载路径冲突。
- 修复混合本地目录被单首下载歌曲的专辑名覆盖的问题。

### 安装与平台说明

需要 **iOS 27.0 或更高版本**。下载 `NeoDizzy-v0.5.0-unsigned.ipa`，使用自己的证书或侧载工具重新签名安装。IPA 未签名，不包含证书或描述文件，不能直接点击安装。

本次不提供 macOS 安装包。macOS 版本暂停开发，历史安装包保留在旧 Release。

自动化测试与模拟器验证不代表实际账号、付款、真机后台播放及侧载签名的全面验收。
