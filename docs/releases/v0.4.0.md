本次更新新增浅色外观和十种主题色，iOS 版新增「正在播放」小组件，并重新设计了专辑页。

### 外观与主题

- iOS 与 Mac 都支持浅色、深色和跟随系统；iOS 版不再固定深色。
- 十种主题色替换原来固定的金色，默认仍是鎏金。iOS 在「我的 › 外观与主题」，Mac 在设置的「外观」标签页。
- App 图标跟随主题色：iOS 切换为同色的图标，Mac 运行时更换 Dock 图标。

### 「正在播放」小组件（iOS）

- 小号方形小组件，显示当前歌曲的封面，轻点打开 App。

### 专辑页（iOS）

- 背景直接取封面边缘的颜色，文字按背景深浅自动使用黑字或白字；背景遮罩可在「外观与主题」中调整（0–100%，默认 5%）。
- 「播放」「随机播放」改为两个等宽按钮；分享和网页链接收进右上角菜单。
- 专辑介绍显示前三行，较长时点「更多」查看完整的介绍与曲目和制作人员。
- 购买卡片只保留一个主要操作。
- 曲目列表行距加大，去掉分割线。
- 社区区块显示 +dB 汇总和短评卡片，可进入完整的短评页并撰写短评。

### 安装

需要 **iOS 27+** / **macOS 27+**。

- **iPhone**：下载 `NeoDizzy-v0.4.0-unsigned.ipa`，使用自己的证书或侧载工具重新签名后安装；此文件未签名，不能直接点击安装。
- **Mac**：下载 `NeoDizzy-macOS-v0.4.0.dmg`，打开后将 NeoDizzy 拖到「应用程序」。App 为 ad-hoc 签名，首次打开若提示无法验证开发者，在「系统设置 → 隐私与安全性」中选择「仍要打开」。

`SHA256SUMS.txt` 用于校验下载完整性：`shasum -a 256 -c SHA256SUMS.txt`。
