NeoDizzy 首个公开版本，非官方 DizzyLab iOS 客户端。

- 黑色背景、金色立体 D 图标，参考 NeoBili 的字母图标样式。
- 专辑、社团、标签、pack 浏览与搜索；试听、已购完整版、后台和锁屏播放。
- 已购专辑下载到所选文件夹，支持 MP3 / FLAC、ZIP 导入及离线播放。
- 数字专辑购买与 BOOST、支付宝收银台、按账号保存待核验付款。
- 点赞、短评、repo 阅读、用户主页、关注动态和支持者排行榜。
- 「随便听听」支持返回上一首与请求新歌曲；页面标题可在设置中切换固定或滚动。
- CI 自动运行核心回归测试、iOS 测试目标编译检查，构建设备 IPA；版本标签触发发布。

### 安装

需要 **iOS 27 或更高版本**。下载 `NeoDizzy-v0.1.0-unsigned.ipa`，使用侧载工具和自己的证书重新签名后安装。此 IPA **未签名**，不能直接点击安装，不包含作者的签名证书。`SHA256SUMS.txt` 用于校验下载文件。

### 当前限制

- 完整版串流需要登录拥有对应专辑的账号；「随便听听」采用网站提供的随机曲目，可能是试听版本。
- pack、购物车、实体商品、PayPal、兑换码及部分 repo 互动仍使用网站。
- 未识别的支付宝网页回跳格式可能需要手动返回 App 继续核验；付款结果以服务端实际订单为准。
- 文件夹需保留本地音频；云盘占位文件不保证离线可用。系统后台下载唤醒等场景仍需进一步验证。

CI 默认执行 156 项核心回归测试，并编译完整 iOS 应用及测试目标。GitHub 的 Xcode 27 模拟器曾在 173 项测试通过后卡住结果收集，因此运行模拟器测试暂作为 Actions 手动运行时的 `run_simulator_tests` 选项；它仍会报告实际失败，不会忽略错误。
