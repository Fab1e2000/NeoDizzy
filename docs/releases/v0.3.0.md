本次更新新增原生 macOS 版，iOS 版新增本地音乐库、本地歌词和音频标签编辑，并修复播放页与导航的几处问题。

### macOS 版（新增）

- 原生 SwiftUI 的 Mac 版，功能与 iOS 版对齐，界面参考「音乐」App，固定深色界面。
- 顶部导航：工具栏正中一组分段按钮切换页面，窗口变窄时只显示图标；搜索是独立页面，保留最近搜索。
- 底部三栏播放条，右侧可拖动调整宽度的歌词 / 待播清单面板；窗口太窄时先自动加宽再展开面板。
- 专辑页参考「音乐」排版，底部显示同一社团的更多作品；悬停封面时提前加载专辑详情。
- 键盘快捷键、媒体键、控制中心「正在播放」、App 沙盒内的文件夹授权，以及网页版收银台购买。

### iOS 版

- **本地库**：独立标签页，汇总下载专辑和第三方音乐；支持多个扫描目录，按文件夹分专辑，读取音频标签、多碟曲序与封面，不改动音乐文件。
- **本地歌词**：播放页可显示手动导入的 LRC / TXT、同目录 LRC 或内嵌歌词，逐行同步、点击跳转。
- **编辑音乐标签**：单曲编辑标题、歌手、专辑等标签和封面；FLAC 专辑可批量编辑。
- **随便听听**改为独立标签页；标签栏可排序、隐藏，并可选择启动页面。
- 修复：播放页的歌词按钮只有图标本身能点中，经常点不动。
- 修复：iOS 27.2 上滑动返回时，专辑页左上角的返回按钮中途移位；现在与系统 App 一样原地淡出。
- 社团与用户头像改为方形，并读取原图：透明背景的社团字标不再显示为整块白色。

### 安装

需要 **iOS 27+** / **macOS 27+**。

- **iPhone**：下载 `NeoDizzy-v0.3.0-unsigned.ipa`，使用自己的证书或侧载工具重新签名后安装；此文件未签名，不能直接点击安装。
- **Mac**：下载 `NeoDizzy-macOS-v0.3.0.dmg`，打开后将 NeoDizzy 拖到「应用程序」。App 为 ad-hoc 签名，首次打开若提示无法验证开发者，在「系统设置 → 隐私与安全性」中选择「仍要打开」。

`SHA256SUMS.txt` 用于校验下载完整性：`shasum -a 256 -c SHA256SUMS.txt`。
