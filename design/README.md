# NeoDizzy 图标规范 · 唱片箱

DizzyLab 是卖专辑的地方，所以图标取自唱片店里一格格翻找的唱片箱：去掉箱子，只留一排立着的专辑。三张封套以侧前方视角向右后方排开，竖边上端右倾成菱形，把整组往右下坠的重心拉回中间。底色为白色，与 Neo 系列其他 App 一致。

设计过程与各版对比在画布「NeoDizzy Logo · 唱片箱」上（R3 圆角更大为定稿）。

## 文件

| 文件 | 用途 |
|---|---|
| `AppIcon.svg` | 1024 母版，白色方形底（由系统裁圆角） |
| `AppIcon-Dark.svg` | 深色外观参考，底色 `#1C1C1E` |
| `Mark.svg` | 彩色图形，透明底，1024 画布 |
| `Mark-Mono.svg` / `Mark-Mono-White.svg` | 单色版，封套之间留 24 的间隙，用于字标、水印和小尺寸 |
| `Lockup.svg` / `Lockup-Dark.svg` | 图标加字标「Neo」细体、「Dizzy」粗体的横向组合 |
| `previews/*.png` | Icon Composer 渲染的 iOS 六种外观（默认、深色、浅/深着色、浅/深透明） |

App 内使用的是 `NeoDizzy/Resources/AppIcons/NeoDizzyIcon.icon`：白色底，三张封套各占一个图层组（`SleeveFront.svg`、`SleeveMiddle.svg`、`SleeveBack.svg`），第一组在最上层。图层只给纯色，玻璃质感、高光和投影都交给 Icon Composer，不要在 SVG 里再加材质或阴影。`AppIcon.appiconset/AppIcon-1024.png` 由 `AppIcon.svg` 导出。

## 构造（1024 画布）

- 每张封套是一个平行四边形：宽 300、高 420；上下边向右下倾斜 140；竖边上端比下端右移 80。
- 三张封套间距 120，红在最前（最左），黄居中，绿在最后。
- 圆角 56，用二次曲线在四个角上各收 56。
- 不按外框居中，而是把三张封套并集的形心放在 (512, 504)，即画布中心略偏上。
- 最终四角（左上、右上、右下、左下，未倒圆角）：
  - 前 · 红：(282.2, 224) (582.2, 364) (502.2, 784) (202.2, 644)
  - 中 · 黄：(402.2, 224) (702.2, 364) (622.2, 784) (322.2, 644)
  - 后 · 绿：(522.2, 224) (822.2, 364) (742.2, 784) (442.2, 644)

## 颜色

三种颜色都是纯色、不透明，前面的封套直接盖住后面的。

| 图层 | 色值 |
|---|---|
| 前 · 红 | `#FFA39B` |
| 中 · 黄 | `#FFD36E` |
| 后 · 绿 | `#93DAA8` |
| 底色 | `#FFFFFF` |
