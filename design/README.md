# NeoDizzy 图标规范 · 汇流·播放

三个圆分别代表 DizzyLab、网易云音乐和本地音乐。三个圆两两重叠，三者共有的部分留白，正好形成一个圆润的播放三角。

## 文件

| 文件 | 用途 |
|---|---|
| `AppIcon.svg` | 1024 母版，白色方形底（由系统裁圆角） |
| `AppIcon-Dark.svg` | 深色外观参考，底色 `#1C1C1E` |
| `Mark.svg` | 彩色图形，透明底，1024 画布 |
| `Mark-Mono.svg` / `Mark-Mono-White.svg` | 单色线稿，用于字标、水印和小尺寸 |
| `Lockup.svg` / `Lockup-Dark.svg` | 图标加字标「Neo」细体、「Dizzy」粗体的横向组合 |

App 内实际使用的是 `NeoDizzy/Resources/AppIcons/NeoDizzyIcon.icon`（图层为 `Mark.svg` 同款的 `Confluence.svg`），`AppIcon.appiconset/AppIcon-1024.png` 由 `AppIcon.svg` 导出。

## 构造（1024 画布）

- 圆半径 209，三个圆心到形心的距离均为 132，右侧一个，左上、左下各一个。
- 先按 190 / 120 设计，再以 512 为中心放大 1.1 倍，安全区 616 × 647。
- 按视觉重心整体**右移 28、上移 7**：左侧两个圆面积更大，形心和明度重心都偏左，位移后两者的平衡点落在画布中心略偏上处。
- 最终圆心：右 (639, 505)，左上 (441, 390.68)，左下 (441, 619.32)。

## 颜色

三种颜色取 OKLCH 中相同的明度 0.70 和饱和度 0.15，只在色相上区分。重叠区按滤色（光线相加）预先算好，SVG 中都是纯色色块，不依赖混合模式。

| 区域 | 色值 |
|---|---|
| 右 · 珊瑚红 | `#ED7668` |
| 左上 · 杏橙 | `#DF8623` |
| 左下 · 草绿 | `#68B457` |
| 红 + 橙 | `#FDBE7D` |
| 红 + 绿 | `#F4D79C` |
| 橙 + 绿 | `#ECDB6E` |
| 核心 · 播放三角 | `#FFFFFF` |
