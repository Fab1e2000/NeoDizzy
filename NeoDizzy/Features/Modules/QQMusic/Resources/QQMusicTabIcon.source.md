原始文件 SHA-256：`71d23506a8c642c88d5fee46d32eae0be0801808d75e1a6972c3328687f91e87`。

- 直接读取原图的 sRGB 调色板和透明度，使用确认预览中的公式：`note = clamp(3 * (G - R), 0, 1)`，`templateAlpha = sourceAlpha * (1 - note)`；RGB 为黑色。原图绿色音符成为模板留空，圆底成为可着色部分。
- 取左侧完整 92×92 图形，等价于将整个 340×92 原图按 `19.8 / 92` 缩放并在 `(2.2, 2.2, 19.8, 19.8)` 内裁切字标；圆底与音符从未分别缩放。
- 输出 72×72 PNG（@3x），固有尺寸 24×24 pt；保留原图抗锯齿后进行高质量缩小，无轮廓重画、锐化或额外描边。
